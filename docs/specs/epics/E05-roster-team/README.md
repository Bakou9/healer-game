# E05 — Personnages et équipe

## Objectif
Un roster d'alliés variés, une équipe de 4 emplacements, une IA d'auto-battle crédible.

## Périmètre
Modèle de personnage, classes, composition, synergies, IA, progression, contenu, interface d'équipe.

## Hors périmètre
Tirages (E06), art (E12).

## Critères de sortie de l'epic
- Le roster de lancement est jouable et équilibré.
- L'IA d'auto-battle est déterministe et testée.
- Chaque composition valide passe la batterie d'équilibrage.
