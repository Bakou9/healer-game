# E03 — Boss et rencontres

## Objectif
Une galerie de boss aux archétypes distincts, qui mettent chacun la pression sur un aspect du soin.

## Périmètre
Archétypes, boss, phases avancées, vagues, modificateurs de difficulté.

## Hors périmètre
Récompenses (E06), campagne (E07).

## Critères de sortie de l'epic
- Au moins 4 boss couvrant les archétypes.
- Chaque boss est viable pour tous les builds (E08).
- Les boss sont des données validées.
