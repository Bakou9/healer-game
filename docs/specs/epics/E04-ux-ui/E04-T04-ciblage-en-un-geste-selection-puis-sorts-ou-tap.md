# E04-T04 — Ciblage en un geste (sélection puis sorts, ou tap direct)

## Contexte
Aujourd'hui : armer un sort puis toucher un allié = 2 étapes, trop lent en temps réel.

## Critères d'acceptation
- [ ] Tap sur un allié = le sélectionne ; les sorts s'y appliquent
- [ ] Geste rapide pour le soin par défaut
- [ ] Annulation évidente
- [ ] Temps moyen par ordre mesuré

## Tests automatiques exigés
Test de la logique de sélection ; mesure de nombre de gestes.

## Impact équilibrage
Oui : change le rythme d'action réalisable, à re-mesurer (profils E08-T01).
