# E07 — Modes de jeu et méta-progression

## Objectif
Des raisons de revenir : campagne, défis, classements, événements.

## Périmètre
Campagne, défi du jour, tour infinie, classements, événements, succès.

## Hors périmètre
Boss (E03), serveur (E10).

## Critères de sortie de l'epic
- La campagne est jouable de bout en bout.
- Chaque mode réutilise le moteur sans le modifier.
